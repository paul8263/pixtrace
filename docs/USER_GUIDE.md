# PixTrace（图迹）用户指南

PixTrace 是一个本地 ComfyUI 生成图像浏览器。它打开一个工作目录，扫描其中的 PNG / JPEG / WebP 图像，解析提示词与生成参数，并在目录内建立可检索的本地索引。

## 1. 安装与启动

### 安装版

运行 `PixTrace_<版本>_x64-setup.exe`（NSIS）或 `.msi`，按向导安装。安装版默认安装到当前用户目录，设置、日志与 WebView2 用户数据写入 `%APPDATA%\PixTrace`。

首次安装时，如果系统缺少 Microsoft Edge WebView2 Runtime，安装程序会引导下载安装。也可以提前从 <https://developer.microsoft.com/microsoft-edge/webview2/> 安装 Evergreen Runtime。

### 便携版

解压 `PixTrace-<版本>-portable-x64.zip` 到任意可写目录，双击 `启动 PixTrace.cmd`。便携版必须保留以下文件：

- `PixTrace.exe`
- `portable.flag`（存在时启用便携模式）
- `启动 PixTrace.cmd`（检查 WebView2 并启动程序）

便携版将设置、日志、WebView2 数据与缓存写入程序目录下的 `data/`，不写注册表。目录可以放在含空格或中文的路径中；如果目录不可写，程序会回退到临时目录并给出提示。

文件名含 `-full` 的便携包自带 WebView2 固定运行时，适合无法联网安装运行时的 Windows 10/11 精简系统。

也可以直接运行 `PixTrace.exe --portable` 强制便携模式，或用 `--installed` 强制安装模式。

## 2. 打开工作目录

启动后点击“打开工作目录”，选择包含 ComfyUI 输出图片的文件夹。PixTrace 会递归扫描子目录，并在工作目录内创建：

- `.pixtrace/index.db`：SQLite 索引与缩略图缓存目录
- `.pixtrace/ratings.json`：评级快照
- `.pixtrace/workspace.lock`：防止同一目录被多个实例同时写入
- `.pixtrace/workspace.owner`：当前占用实例的 PID 与启动时间（诊断用）

扫描期间可以立即浏览与搜索，索引在后台继续；底部状态栏显示进度。索引完成后结果自动刷新。

### 文件监听

默认开启。新增、修改或删除图片后，约 2 秒内自动刷新。网络盘、同步盘上的文件事件可能不可靠，此时可在“设置”中关闭监听，并使用“重新扫描目录”手动刷新。

### 重新扫描与重建索引

- **重新扫描目录**：只处理新增或修改过的文件，速度快，日常使用。
- **重建提示词索引**：重新解析全部图片的提示词与参数。升级解析器或怀疑索引异常时使用。

## 3. 浏览与详情

- 网格支持滚动加载，点击图像打开详情。
- 详情视图中滚轮缩放、拖拽平移，工具栏可切换“适应窗口”与 1:1。
- 右侧面板显示正负提示词、模型、LoRA、采样器、步数、CFG、种子、分辨率、文件信息，以及原始提示词 JSON / 工作流 JSON。
- 底部胶片条可在当前结果集中前后切换。
- `Esc` 关闭详情。

### 删除图片

在网格中右键图片，选择“删除图片…”：

- **移到回收站**（默认）：从工作目录移除文件，但可从 Windows 回收站恢复。
- **永久删除**：直接从磁盘移除，无法恢复。

删除的是工作目录中的原始文件，索引、搜索结果与提示词分组会同步刷新；评级仍按相对路径保留，文件恢复后评级会重新生效。删除过程中会暂停后台索引，完成后自动恢复。

## 4. 搜索与筛选

顶部搜索框支持：

| 语法 | 说明 | 示例 |
| --- | --- | --- |
| 空格 | 多个词同时匹配（AND） | `masterpiece 1girl` |
| `"短语"` | 精确短语 | `"red dress"` |
| `-词` | 排除 | `masterpiece -lowres` |

英文按词切分并保留下划线，中文、日文、韩文使用分词器。搜索框有 280ms 防抖，回车立即检索，`Esc` 清空，`Ctrl+F` 聚焦。

左侧栏可按模型、采样器、是否包含工作流筛选，也可按评级筛选：

- 未评级
- 至少 N 星
- 恰好 N 星

工具栏可切换排序：相关度、最新、路径、评级。

## 5. 评级、分组与对比

- 在网格中悬停星级，或打开详情后按数字键 `1`–`5` 评级；点击当前星级可清除。
- 评级按相对路径保存，文件移动或索引重建后仍会保留；文件恢复后评级自动生效。
- 每次评级会更新 `.pixtrace/ratings.json`。删除 `index.db` 后重新打开目录，评级会自动恢复。
- 切换到“提示词分组”，可查看相同（规范化后）正面提示词的图像组，按数量或最近排序。
- 在网格中勾选 2–4 张图像，点击底部“对比”进入对比视图。对比视图支持同步缩放/平移、同步开关与参数差异表。

## 6. 缓存管理

缩略图按需生成并保存在 `.pixtrace/cache/thumbs`。默认缓存上限 2 GB，超过上限时按最近使用时间自动清理最旧的缩略图。

在“设置”中可查看：

- 缩略图数量与占用空间
- 索引数据库大小
- 当前缓存上限与使用比例

可以修改上限（64 MB – 100 GB）或点击“清理缓存”。清理后浏览时会重新生成缩略图，不影响原始图像与评级。

## 7. 常见问题

**打开目录时报“工作目录已被另一个 PixTrace 实例打开”**

同一工作目录同时只允许一个实例写入。关闭另一个窗口，或复制目录后再打开。若确认没有其他实例，检查 `.pixtrace/workspace.lock` 是否被残留进程占用。

**目录不可写 / 只读**

PixTrace 需要在工作目录内创建 `.pixtrace/`。只读 U 盘、受保护目录或权限不足时无法建立索引。请将目录复制到可写位置，或调整目录权限。

**网络盘上的索引或文件监听不稳定**

SQLite 在网络盘上可能遇到锁与 WAL 问题，文件监听也可能丢失事件。建议将工作目录放在本地磁盘。网络路径会显示降级提示，可使用“重新扫描目录”手动刷新。

**便携版提示缺少 WebView2**

安装 Microsoft Edge WebView2 Runtime，或改用文件名含 `-full` 的完整版便携包。启动脚本会检测注册表与运行时目录，缺失时给出提示。

**Windows 提示“已保护你的电脑”**

未签名程序可能触发 SmartScreen。请从官方发布页下载，并核对 `SHA256SUMS.txt` 中的 SHA-256。正式发布产物应使用代码签名证书签名。

**索引很大，能否删除**

可以删除整个 `.pixtrace/`，只会丢失索引与缩略图缓存；评级可从 `ratings.json` 恢复。若要保留评级，只删除 `index.db` 与 `cache/`，不要删除 `ratings.json`。

**误删了图片**

如果删除时选择的是“移到回收站”，可在 Windows 回收站中还原；还原后重新扫描目录或等待文件监听刷新即可。选择“永久删除”的文件无法通过 PixTrace 恢复。

**移动工作目录**

`.pixtrace/` 与相对路径索引会随目录一起移动。移动后重新打开目录即可；若路径变化导致文件事件异常，执行一次“重新扫描目录”。

**日志在哪里**

安装版：`%APPDATA%\PixTrace\logs`；便携版：程序目录 `data\logs`。反馈问题时附上最近日志。

## 8. 发布与校验

发布产物包括：

- NSIS 安装包（`.exe`）
- MSI 安装包（`.msi`）
- 便携版 zip（普通版 / `-full` 自带 WebView2 运行时）
- `SHA256SUMS.txt`

校验示例（PowerShell）：

```powershell
Get-FileHash .\PixTrace-0.1.0-portable-x64.zip -Algorithm SHA256
```

构建与发布脚本见仓库 `README.md` 与 `scripts/`。
